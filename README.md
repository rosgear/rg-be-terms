## <img src="https://raw.githubusercontent.com/rosgear/rg-be-terms/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Термины»

Модуль входит в состав Панели управления GePanel.

Модуль терминов компонентов веб‑приложения RosGear предназначен для систематизации и управления терминологией, используемой в модулях и расширениях модулей, с целью обеспечения единообразия документации и интерфейса.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-terms
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-terms": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-terms/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-terms/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Terms»

The module is part of the GePanel Control Panel.

The RosGear web application component terminology module is designed to systematize and manage terminology used in modules and module extensions in order to ensure consistency in documentation and interface.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-terms
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-terms": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-terms/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
